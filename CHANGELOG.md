# Зміни

Формат: кожна версія — розділ `## vX.Y.Z`. Текст розділу автоматично стає описом релізу на GitHub.

## v2.2.0

Перевірено: NetScaler 14.1 build 73.46.

### NetScaler
- Українською тепер і старі сторінки `/vpn` та `/epa`, які не входять до порталу RfWebUI: сторінка після виходу
  («Вихід успішно виконано»), перевірка пристрою EPA та її помилки, помилки VPN, зміна пароля, перенесення сеансу,
  безклієнтський доступ до файлів. Пакет кладе `uk.xml` у ресурси кожної теми й додає `uk` до `config.xml` теми.
- `status` показує стан кожної теми; `check` перевіряє й ці рядки (у `en.manifest` додано 504 рядки `xml:`).
- `uninstall` повертає `config.xml` тем до оригіналу байт у байт.

### Встановлення
- Оновлення з 2.x: так само, як встановлення (`install`), потім очищення кешу.

## v2.1.1

Перевірено: NetScaler 14.1 build 73.46; StoreFront 2507 (7.45) і 2607 LTSR на Windows Server 2025.

### NetScaler
- Надійніше відновлення після перезавантаження: під час завантаження пакет встановлюється у фоні й ще кілька хвилин
  перевіряє, що файли порталу не замінено. Перевірено звичайним холодним завантаженням (без `reboot -warm`).
- Порожній або відсутній `/nsconfig/rc.netscaler` — нормальна ситуація, файл буде створено.
- Підказка: помилка `flush cache contentGroup loginstaticobjects` зазвичай означає, що Integrated Caching вимкнено,
  і очищати нічого.

### StoreFront
- Підтримка StoreFront 2607 LTSR: перекладено нове повідомлення форми входу `UnexpectedErrorOccurred`,
  оновлено рік у копірайті.
- Маніфести для кожної перевіреної версії (`en.2507.manifest`, `en.2607.manifest`); `-Check` сам обирає маніфест
  встановленої версії.

### Встановлення
- Оновлення з 2.x: так само, як встановлення (NetScaler — `install`, StoreFront — `-RecycleAuthPool`).

## v2.1.0

Перевірено: NetScaler 14.1 build 73.46; StoreFront 2507 (7.45) на Windows Server 2025.

### Перевірка нового білду
- NetScaler: `ua_langpack.sh check` — після оновлення прошивки показує нові рядки (немає перекладу) і рядки зі зміненим
  англійським текстом. Якщо прошивка змінила рядки, під час завантаження в журнал пишеться нагадування.
- StoreFront: `Install-UALangPack.ps1 -Check` — те саме для інтерфейсу та форми входу.
- У пакеті є `en.manifest` — контрольні суми англійських рядків білду, під який зроблено переклад.

### StoreFront
- Перекладено 17 рядків, які з'явилися в StoreFront 2507 (PWA, Google Play / App Store, заборона завантаження ICA,
  Citrix Workspace Web Extension тощо).
- Додано `ExplicitJson.uk.resx`.
- Оновлено 5 рядків, чий англійський текст змінився: «Citrix Receiver» → «застосунок Citrix Workspace», пункти меню
  «Змінити спосіб запуску» та «Використовувати веб-браузер».
- Прибрано 10 дублікатів ключів у `wrstrings.uk.js` (поведінка не змінилася).

### Встановлення
- Оновлення з 2.0: так само, як встановлення (NetScaler — `install`, StoreFront — `-RecycleAuthPool`).

## v2.0.0

Перевірено: NetScaler 14.1 build 73.46; StoreFront 2507 (7.45) на Windows Server 2025.

### NetScaler
- Українська тепер окрема мова (`uk`), а не підміна російської. Мова обирається за мовою браузера; російська — оригінальна.
- Працює у всіх темах на базі RfWebUI та WStheme, включно з власними.
- Встановлення однією командою (`ua_langpack.sh install`); після перезавантаження та оновлення прошивки пакет відновлюється сам.
- Додано переклад повідомлень, яких бракувало: згода на сканування EPA, помилки EPA, вимога Citrix Secure Access тощо.
- Виправлено 7 повідомлень сервера (зміна пароля, перевищення спроб входу, …), які показувалися англійською через пошкоджені ключі.
- Підписи теми для української — у `strings.uk.json` теми.

### StoreFront
- Працює на StoreFront з Content Security Policy (2507): спосіб підключення з 1.x блокувався, сторінка лишалася англійською.
- Встановлення однією командою (`Install-UALangPack.ps1`): знаходить усі Store через IIS, робить резервну копію, не перезаписує ваш `script.js`.
- Форма входу перекладається одразу (`-RecycleAuthPool`).
- Власні рядки `custom\strings.uk.js` тепер підключаються для української.

### Загальне
- Єдиний термін «застосунок» замість «додаток».
- Назва мови: «Українська».

### Відомі обмеження
- StoreFront 2507: 17 нових рядків інтерфейсу поки англійською (буде у v2.1).
- Новий інтерфейс StoreFront Workspace не перекладається; плагін EPA — мовою ОС.
