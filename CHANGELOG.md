# Зміни

Формат: кожна версія — розділ `## vX.Y.Z`. Текст розділу автоматично стає описом релізу на GitHub.

## v2.0.0

Перевірено: NetScaler 14.1 build 73.46; StoreFront 2507 (7.45) на Windows Server 2025.

### NetScaler
- Українська тепер окрема мова (`uk`), а не підміна російської. Мова обирається за мовою браузера; російська — оригінальна.
- Працює у всіх темах на базі RfWebUI та WStheme, включно з власними.
- Встановлення однією командою (`ua_langpack.sh install`); після перезавантаження та оновлення прошивки пакет відновлюється сам.
- Додано переклад повідомлень, яких бракувало: згода на сканування EPA, помилки EPA, вимога Citrix Secure Access тощо.
- Виправлено 7 повідомлень сервера (зміна пароля, перевищення спроб входу, …), які показувалися англійською через пошкоджені ключі.
- Підписи теми для української — у `strings.uk.json` теми.

### StoreFront
- Працює на StoreFront з Content Security Policy (2507): спосіб підключення з 1.x блокувався, сторінка лишалася англійською.
- Встановлення однією командою (`Install-UALangPack.ps1`): знаходить усі Store через IIS, робить резервну копію, не перезаписує ваш `script.js`.
- Форма входу перекладається одразу (`-RecycleAuthPool`).
- Власні рядки `custom\strings.uk.js` тепер підключаються для української.

### Загальне
- Єдиний термін «застосунок» замість «додаток».
- Назва мови: «Українська».

### Відомі обмеження
- StoreFront 2507: 17 нових рядків інтерфейсу поки англійською (буде у v2.1).
- Новий інтерфейс StoreFront Workspace не перекладається; плагін EPA — мовою ОС.
